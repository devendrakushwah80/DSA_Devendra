# 🧠 Binary Search Main Sub-Patterns

### 1. Classic Binary Search

Search for a target in a sorted search space.

### 2. Lower Bound / Upper Bound

Find the first or last position satisfying a condition.

### 3. Binary Search on Rotated Array

Determine which half is sorted and eliminate the other half.

### 4. Binary Search on Answer

Search over a range of possible answers instead of directly searching an array.

Common recognition:

* Minimum possible maximum
* Maximum possible minimum
* Minimum capacity
* Minimum speed
* Minimum days
* Maximum distance

### 5. Peak Finding

Use the direction/slope around the middle element to eliminate half of the search space.

### 6. 2D Binary Search

Apply binary search to matrices using either:

* Flattened matrix indexing
* Row/column properties
* Binary search on value range

### 7. Binary Search with Duplicates

Handle cases where duplicates prevent directly identifying the sorted half.
